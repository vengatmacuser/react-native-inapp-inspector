Built for Modern Mobile Developers

A comprehensive runtime toolbox to audit, verify, and diagnose your React Native application states in real-time.

🌐 Network Waterfall & P95

Hooks into `fetch`, Axios, and XHR. Inspect status codes, request/response headers, JSON trees, latency waterfall bars, P95 telemetry, and export as cURL or Fetch.

⚡ WebSocket & Socket.IO

Intercept native WebSocket (`ws://`, `wss://`) and Socket.IO v2/v3/v4 frames. Inspect live bidirectional packet timeline, text/binary payloads, and ping/pong heartbeats.

💾 Storage Manager (CRUD)

Unified live explorer for `@react-native-async-storage/async-storage` and `react-native-mmkv`. Browse, search, edit, create, or delete keys and JSON values in real-time.

🔔 Push Notification Logger

Intercept FCM, APNs, Salesforce, OneSignal, and Notifee. Track foreground/background app state, payload parameters, deep links, and user notification action clicks.

🪵 Console & Metro Symbolication

Intercepts `console.log/warn/error`. Automatically maps minified stack traces back to exact project TypeScript files and line numbers (`HomeScreen.tsx:42:15`).

🔄 Redux State & Action Diffs

Connects to Redux Store and RTK. Inspect dispatched action history, payload inspection, color-coded state diffs (added/updated/deleted), and `redux-persist` metadata.

🛡️ Crash Guard & Breadcrumbs

Fault-isolated Micro-UI architecture. Global React Error Boundary with user navigation, network, and Redux breadcrumbs leading up to any unhandled crash.

📱 Native Hardware & RAM

Direct Kotlin & Obj-C bridge querying Total RAM, Free RAM, native heap, storage space, battery %, charging state, CPU ABI, and real-time display FPS monitoring.

📸 Screen Capture & Video Suite

Take high-resolution full-window screenshots, record smooth MP4 screen video walkthroughs with mic narration, and generate animated GIFs for GitHub PRs and Jira tickets.

🌍 25 Global Languages

Full localization across 25 global languages and regions (English, Chinese, Hindi, Japanese, Spanish, German, etc.) with an interactive bottom sheet and country picker.

Simple Integration

Add the complete inspector suite to your app in under three minutes.

1

Install Dependencies

Add react-native-inapp-inspector and react-native-svg to your project.

2

Initialize at Entry File

Call setupNetworkLogger(), setupConsoleLogger(), and setupSocketLogger() before root mounts.

3

Mount the Overlay

Place <NetworkInspector /> in your root JSX layout. Shake device or tap the floating bubble to inspect!

App.tsx 
import React from 'react';
import { SafeAreaView } from 'react-native';
import NetworkInspector, {
  setupNetworkLogger,
  setupConsoleLogger,
  setupSocketLogger,
  connectReduxStore,
  connectAsyncStorage,
} from 'react-native-inapp-inspector';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { store } from './src/store';

// ⚡ Initialize loggers before application renders
setupNetworkLogger();
setupConsoleLogger();
setupSocketLogger();
if (store) connectReduxStore(store);
connectAsyncStorage(AsyncStorage);

export default function App() {
  return (
    <SafeAreaView style={{ flex: 1 }}>
      {/* Your application components */}
      <AppNavigation />
      
      {/* In-App Debugger Overlay */}
      {__DEV__ && <NetworkInspector enabled={true} environment="DEV" />}
    </SafeAreaView>
  );
}
