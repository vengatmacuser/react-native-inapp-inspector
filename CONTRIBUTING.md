First off, thank you for taking the time to contribute! 🎉 Contributions of any kind are welcome.

This document details guidelines on how you can contribute, set up the development environment, and support the project.

## How Can I Contribute?

### 1. Reporting Bugs
- Search existing issues to see if the bug has already been reported.
- If not, open a new issue containing:
  - A clear title and description.
  - Step-by-step instructions to reproduce the issue.
  - React Native, iOS/Android version, and library version.
  - Relevant code snippets, logs, or screenshots/videos of the bug.

### 2. Suggesting Enhancements
- Open a new issue outlining the feature request.
- Explain the use case and why it would be beneficial to other users of the library.

### 3. Pull Requests
- Fork the repository and create your branch from `main`.
- Install dependencies in the root:
  ```bash
  npm install
  ```
- Run the TypeScript build to make sure your changes compile:
  ```bash
  npm run build
  ```
- Test your changes in the local example app located in the `example/` directory.
- Open a Pull Request referencing the issue your changes address.
